# Kira

A playful calico ninja cat with jade eyes, a full ninja outfit, a sheathed katana, and a soft spot for purring between acrobatic flips.

**Creator:** [Omar Tavarez / Designed by Omar](https://www.designedbyomar.com/)

**License:** [CC BY 4.0](../../LICENSE)

## Install

Copy this entire folder to `~/.codex/pets/kira/`, then choose **Kira** in Codex pet settings.

## Contents

- `pet.json` — Codex v2 manifest
- `spritesheet.webp` — validated 8 × 11 animation atlas
- `preview.gif` — work-motion preview
- `attribution.txt` — creator and licensing details
